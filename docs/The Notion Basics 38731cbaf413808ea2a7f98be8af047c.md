# The Notion Basics

- [x]  Create an account with Notion
- [x]  [Download the desktop app](https://notion.so/dynamic-download/desktop) to unlock offline mode and take Notion with you wherever you go
- [x]  Start building with Notion Agent ‣. Tell it what you’re here to do, and Agent will create it for you in seconds.
- [x]  Click anywhere below and **type `/`** to see what you can create – headers, tables, to-do’s, etc.
    - [ ]  Type `/page` to add a **new page** and nest anything, anywhere
- [x]  **Find**, **organize**, and **add new pages** using the sidebar to the left 👈
    - [x]  Make a new page and type `/meet` to capture meeting notes and thoughts effortlessly
        - [x]  Afterwards, find all your meetings in one place in the [**Meetings tab**](https://www.notion.so/meet)
- This is a toggle block. Click the little triangle to see a few more useful tips!
    - Click ‣ **Marketplace** in your sidebar to try setups from our incredible community
    - Check out [Notion Academy](https://academy.notion.com?utm_campaign=gsqw) to level up your Notion knowledge through guided courses (and earn badges while you’re at it!)
